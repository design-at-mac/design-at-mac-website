Design@Mac landing page
=======================

Open index.html in a web browser to view the page.

To add or edit links:
1. Open index.html in a text editor.
2. Find the section marked "TO ADD OR EDIT A LINK".
3. For a placeholder, replace href="#" with the new URL.
4. Replace "Future link" and its description.
5. Remove class="placeholder", aria-disabled="true", and onclick="return false;".

Files:
- index.html: page content and links
- styles.css: colours, spacing, and responsive design
- assets/design-at-mac-logo.png: supplied Design@Mac logo
